# AI-контракт

## Статус реализации

Работает локальная детерминированная заглушка, разрешённая разделом 5 технического задания. Это не вызов языковой модели. Она анализирует наличие полей и генерирует вопросы из тематических шаблонов. Контекст сохраняется дословно, остальные поля заполняет пользователь. При полной карточке заглушка возвращает минимум три проверочных вопроса.

## Промпт

Ты помогаешь бизнесу уточнить задачу для студентов. Вход: JSON `{draft, topic, fields}`. Только факты пользователя. Не заполняй пропуски догадками. Верни JSON `{mode, questions: [{field, question}], fields}`. Не менее 3 уместных вопросов о пропущенных или неясных полях. `fields` содержит только предоставленные пользователем значения. Пользователь редактирует и подтверждает карточку. Не оценивай и не назначай команды.

## Пример входа

```json
{
  "draft": "У кофейни остаётся выпечка. Хотим точнее планировать закупки.",
  "topic": "Ритейл",
  "fields": {}
}
```

## Пример выходного контракта

Ниже сокращённый пример на три вопроса. Работающая заглушка вернёт вопросы по всем пропущенным полям.

```json
{
  "mode": "local-stub",
  "questions": [
    {"field":"users","question":"Кто будет пользоваться решением и какую задачу эти люди решают?"},
    {"field":"data","question":"Есть ли история продаж, остатков или обращений? В каком формате и за какой период?"},
    {"field":"criteria","question":"По каким измеримым показателям вы примете результат?"}
  ],
  "fields": {
    "title":"",
    "context":"У кофейни остаётся выпечка. Хотим точнее планировать закупки.",
    "need":"", "users":"", "data":"", "constraints":"",
    "result":"", "criteria":"", "contact":"", "interaction":""
  }
}
```

## Некорректный ответ

`validate_ai_result` отклоняет не-объект, отсутствие списка вопросов, менее трёх вопросов, неизвестные имена полей, пустые или слишком короткие вопросы и любое изменение исходных полей. HTTP API возвращает ошибку в JSON, интерфейс показывает её, оставляет черновик на месте и снимает блокировку кнопки. Автотест `test_malformed_ai_output` проверяет эти ветки. Это демонстрирует обработку повреждённого ответа без имитации работающего внешнего API.

## Подключение модели в следующей версии

Заменить формирование `questions` внутри `ai_questions` вызовом модели на сервере. Сохранять ключ только в переменной окружения. Задать таймаут и ограничение длины ответа. Проверить JSON через `validate_ai_result` и сохранить исходные `fields` без изменений. В случае недоступности сети явно обозначить переход на локальную заглушку. Карточка, рейтинг и решения бизнеса продолжат работать независимо.

С текущей строгой проверкой модель может формулировать вопросы, но не перефразировать и не добавлять факты в `fields`. Для будущего извлечения фактов понадобится отдельный контракт с цитатами-основаниями и проверкой человеком. Это расширение в поставку не входит.
